      How the figures are calculated
      • Incidencias = ticket type Failure; OTs = every other type (Work order, Information request…).
      • Escalada = the Third party reference points to a vendor: STA- Ericsson, H- Huawei, 1- Nokia.
      • Devuelta = Current action is “DEVUELTO”.
      • Resuelta = status is not Current and the Restoration date is before the end of the week (so past weeks show the situation at the time).
      • Backlog = cases created before the week, not returned and still unresolved when the week starts.
      • All tickets count, whoever opened them (the SLM groups XSP00025 / XSP00027 are treated like any other initiator). Abiertas por el SLM only shows how many of the new cases were opened by those groups.
      • Gestor = first part of Current action (“GESTOR - PROBLEMA - TÉCNICO”); spelling variants (NFM-T / NFMT, ENM 3 / ENM3…) are merged. Every new incidencia is counted once, so the totals of 2.2 always equal “Nuevos durante la semana”.
      • Nothing created or resolved after the end of the report week is counted, so a past week can be regenerated at any time with the same figures.
      • Weeks are ISO weeks (Monday–Sunday) calculated from the Creation date.
